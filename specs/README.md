# Specs

One folder per feature slice, built in order. A spec is done only when its gate passes.

| Spec                                 | Name                                         | Gate                                                                                                                       | Status                                                                                                                                                                                     |
| ------------------------------------ | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [000](000-foundation)                | Foundation                                   | CI green on a blank app, including the licence-header check, with licence and attribution files in place                   | Done, except that CI as a whole is red until the known layout-gap tests are fixed (see 001 research)                                                                                       |
| [001](001-create-and-export-collage) | Create and export a collage                  | User story walkthrough passes end to end in all three browsers                                                             | Implemented; passes in Chromium locally, Firefox and WebKit are covered by the CI matrix and not yet run; tiling tests knowingly fail                                                      |
| [002](002-collage-editing)           | Collage editing                              | Swap and border changes appear identically in preview and export                                                           | Done (Chromium)                                                                                                                                                                            |
| [003](003-export-quality-and-limits) | Export quality and limits                    | Export of 100 photos completes without tab crash; downscaled output compared against a reference and accepted by the owner | Crash gate passes in Chromium; owner reference comparison still open                                                                                                                       |
| [004](004-packaging)                 | Packaging                                    | `docker compose up` serves the working app                                                                                 | Files complete; nginx config and the full e2e suite verified against nginx; the image itself could not be built in the authoring sandbox (no Docker daemon), the CI `docker` job builds it |
| [005](005-localisation-and-polish)   | Localisation and polish                      | Keyboard-only run through the main flow; at least one non-English language shown                                           | Done (Chromium)                                                                                                                                                                            |
| [006](006-column-control)            | Column control                               | The number of columns can be set and is respected in preview and export                                                    | Done (Chromium)                                                                                                                                                                            |

Spec Kit's CLI could not be installed in the authoring environment (installing from
an external git source was not permitted), so these documents follow Spec Kit's
layout by hand: `.specify/memory/constitution.md`, then `spec.md`, `plan.md`,
`tasks.md` per feature.
