# User guide

Collage Creator makes a collage from your photos: it arranges them for you, and you change
the arrangement, the size and the look until you like it, then save it. It runs entirely in your
browser. Nothing is uploaded, nothing needs installing, and there is no account.

Open it at <https://briggsyj.github.io/CollageCreator/> (or on your own copy, see
[Deployment](../technical/deployment.md)).

## The screen

On a computer:

- **Sidebar** (left), in three steps:
  1. **Photos**: add photos, see them in a list (grouped by page), and the selected photo's
     page and Remove button.
  2. **Poster**: the number of pages, the output size and its shape.
  3. **Style**: the layout, columns, shuffling, border, corners and the seed.
- **Preview** (middle): the collage as it will be saved. Pan and zoom it freely; zooming never
  changes the saved image.
- **Tools** (right): Pan, Swap and Select; the **photo actions** (Wider, Taller, Crop) while a
  photo is selected; and zoom.
- **Save panel** (bottom right): the format (PNG, JPEG or PDF) and the Save button.
- **Help** (`?`, bottom left) explains the tools and lists the keyboard shortcuts.

On a phone the steps open as sheets from a bar at the bottom (Photos, Poster, Style, Save), the
tools float along the top, and a bar above the tabs shows the selected photo.
