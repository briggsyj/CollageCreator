# Size and style

## Output size (Poster step)

| Size   | Pixels (landscape) | Notes                              |
| ------ | ------------------ | ---------------------------------- |
| Screen | 1600 × 1200        | the default                        |
| Small  | 800 × 600          |                                    |
| Square | 1080 × 1080        |                                    |
| A4     | 3508 × 2480        | 300 DPI print sizes                |
| A3     | 4961 × 3508        |                                    |
| A2     | 7016 × 4961        |                                    |
| B1     | 11811 × 8350       | many browsers reduce it, see below |
| Custom | any                | type a width and height            |

**Landscape** and **Portrait** turn the size. Changing the size reshapes every page without moving
photos between pages.

Browsers limit how big an image they can make, and the limits differ a lot (iPhones are the
smallest). If a size is too big for this browser, the app uses the largest it can and says so
under the size buttons.

## Instagram post

**Instagram post** makes one wide collage that is saved as 2 to 20 square images, left to right,
for a carousel post. The preview shows dashed cut marks with scissors where it will be cut. Choose
the number of images and the pixel size of each square (1080 by default). With several pages,
every page becomes a post of that many images.

PDF is not offered for an Instagram post.

## Border and corners (Style step)

- **Thickness**: from none to a tenth of the collage's longer side.
- **Colour**: pick a swatch or any colour.
- **Outer border**: whether the border also runs around the edge of the collage, or only between
  photos.
- **Corners**: square, slightly rounded or rounded.

The preview and the saved image always match.
