# Browser assistants (WebMCP)

Some browsers are adding built-in AI assistants that can use a web page's own tools, through a
proposed standard called WebMCP. Collage Creator offers one tool for each thing you can do with its
controls, so an assistant can arrange and save a collage for you, for example: "three columns,
rounded corners, A4 portrait, then save it as a PDF".

- **You stay in charge.** You see every change in the preview, and your own controls keep working.
  Anything the app asks before doing (removing photos or a page, Remove all, shuffling after hand
  edits) still asks **you**; the assistant waits for your answer.
- **Adding photos is yours.** There is no tool for it: you add photos with the usual button or by
  dropping them (a desktop assistant may operate the browser's file chooser for you).
- **Privacy.** The assistant can read the collage's state and see small previews of the photos so
  it can judge them. The app sends nothing anywhere itself; what the assistant does with what it
  reads is up to the assistant you use.
- **No assistant, no change.** In browsers without WebMCP nothing is shown and nothing changes.

The full list of tools is in the [WebMCP reference](../technical/webmcp.md).
