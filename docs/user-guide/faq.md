# FAQ and troubleshooting

**Does it upload my photos?**
No. Everything happens in your browser; see [Privacy](privacy-and-storage.md).

**Does it work offline?**
Yes, once the page has loaded.

**Why is part of a photo cut off?**
Every photo fills its cell, so photos whose shape differs from the cell are trimmed. Try
**Shuffle layout**, another column count, **Gallery**, or make the photo **Wider** or **Taller**.
**Crop** chooses which part shows.

**The saved image is smaller than the size I chose.**
The browser cannot make an image that big; the app used the largest it can and said so under
the size buttons. Desktop browsers allow much larger images than phones.

**My iPhone photos (HEIC) do not load.**
They should, in any browser: a decoder is loaded the first time one is needed. If a file still
fails, it is listed under **Details** in the notice; converting it to JPEG will work.

**I refreshed and my work is gone.**
Private windows (and some privacy settings) do not let sites store files. Use a normal window.

**How do I get the same arrangement again?**
Keep the address (it holds the seed) or note the seed in **Technical configuration**. The same
photos, settings and seed give the same collage.

**Can I make a photo book?**
Yes: add pages, then save as **PDF** for one document, or PNG/JPEG for a zip of images.

**Why can I not choose PDF?**
PDF is not offered for an Instagram post, which is saved as square images to post.

**Which browsers are supported?**
Current versions of Chrome, Edge, Firefox and Safari, on desktop and mobile. The tests run in
Chromium, Firefox and WebKit.

**Something is wrong.**
Please [open an issue](https://github.com/briggsyj/CollageCreator/issues) with your browser and
what you did. Never attach photos you do not want to share publicly.
