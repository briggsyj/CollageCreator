# Keyboard and touch

## Keyboard

Every control can be reached with Tab and used with Enter or Space. The preview has its own keys
when it has the focus (click it, or Tab to it):

| Key                | Does                                                         |
| ------------------ | ------------------------------------------------------------ |
| Arrow keys         | move between photos (a ring shows the photo)                 |
| Enter              | pick the ringed photo; Enter on a second photo swaps the two |
| Escape             | let go of the selection                                      |
| Delete / Backspace | remove the selected (or ringed) photo, after asking          |
| Ctrl+Z / ⌘Z        | undo the last removal                                        |
| + / −              | zoom in / out                                                |
| 0                  | fit the whole collage                                        |
| Shift + arrows     | pan                                                          |
| Space (hold)       | pan with the mouse, from any tool                            |

With a photo selected (and not typing in a field):

| Key                         | Does                           |
| --------------------------- | ------------------------------ |
| W                           | Wider                          |
| T                           | Taller (steps 2, 3, back to 1) |
| C                           | Crop on or off                 |
| Enter                       | finish cropping                |
| Arrow keys (while cropping) | nudge the photo in its cell    |

The Help dialog lists these too. In dialogs, Enter confirms and Escape cancels.

## Touch

- **Pinch** with two fingers to zoom the preview; move them to pan. This works with every tool.
- **Tap** a photo with the Select tool to select it; a bar above the tabs shows it.
- **Drag** with one finger in Pan to move around; with Swap, drag a photo onto another.
- In the **Photos** step, **press and hold** a photo, then drag it onto another page.
- Steps open as sheets from the bottom bar; pull a sheet down by its handle to close it.
