# Internationalisation

## How it works

- Interface text is written in English and wrapped in `t()` (TypeScript) or `tr()` (Svelte components,
  which also re-renders when the language changes). The English string is the key.
- Translations come from gettext `.po` files in `src/i18n/po/`, loaded at build time
  (`import.meta.glob`) and parsed by `src/i18n/po.ts`. They are the original PhotoCollage catalogues, with
  the translators' credits intact.
- Strings added since the original are shown in English until translated.
- Placeholders use `%(name)s`, as in the original: `t("Added page %(n)s.", { n: 2 })`.

## Languages

English plus Bulgarian, Czech, Dutch, French, German, Italian, Polish, Portuguese (Brazil), Russian,
Spanish and Ukrainian. The app starts in a language chosen earlier, else the browser's preferred language
(matched exactly, then by base language), else English. The choice is stored in `localStorage` and sets the
page's `lang` attribute.

## Translating

```sh
npm run check:i18n             # untranslated strings per language
npm run check:i18n -- --list   # the strings themselves
```

Add `msgid`/`msgstr` pairs to the language's `.po` file (keep the header and credits). To add a language,
add `src/i18n/po/<code>.po` (for example `ja.po`); it appears in the language menu automatically. Add your
credit to the file's header and to [NOTICE.md](../../NOTICE.md).

Keep strings short, plain and complete sentences where they are sentences; avoid building sentences from
pieces, which do not translate.
